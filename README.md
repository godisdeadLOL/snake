# Змейка
В отличие от классической версии, движение не привязано к сетке, а тело змеи создается динамически с помощью процедурной генерации меша.

---

## 🕹️ Демо
[Поиграть можно по ссылке](https://godisdeadlol.github.io/snake)

## ✨ Особенности
- 🐍 Динамическая генерация меша тела змеи
- 🎮 Виртуальный джойстик для управления
- 💥 Простая система частиц
- 📈 Сохранение рекорда в LocalStorage
- 📱 Поддержка мобильных устройств

## 🚀 Запуск
```bash
git clone https://github.com/godisdeadLOL/snake.git
cd snake
npm install
npm run dev
```
